# Slimefun 自动合成助手

基于 JsMacros 的粘液科技配方读取、材料计算、仓储补货与自动合成工具。

> 当前版本：V4.5.4  
> 维护者：Jerinin  
> 运行环境：Minecraft 客户端 + JsMacros

## 功能概览

| 功能 | 说明 |
| --- | --- |
| 配方读取 | 从粘液科技指南批量读取分类配方，或单独读取当前配方 |
| 材料计算 | 自动分析配方依赖、现有库存和缺失材料 |
| 合成队列 | 根据依赖关系生成合理的自动合成顺序 |
| 仓储补货 | 扫描附近容器，校验实时槽位后自动取出材料 |
| 工作站执行 | 支持配置化的单方块及多方块工作站自动合成 |
| 黑名单 | 排除不希望自动拆分或自动处理的配方 |
| HUD | 显示制作列表、材料列表和合成队列 |
| 配置管理器 | 使用本地网页编辑并导出工作站配置 |

## V4.5.4 亮点

- HUD 文字加粗并优化分层配色，在明亮背景下更容易辨认
- 指南操作按钮移动到界面右侧，减少对 HUD 和视野的遮挡
- 材料不足或本轮无产出时主动停止，避免自动合成无限空转
- 产物切换增加失败退出限制，避免工作站配置不匹配时卡住
- 仓储取料前校验实时槽位，降低缓存变化导致拿错物品的风险
- 工作站清空或产物收取失败时中止流程，防止队列状态失真
- 修复快捷合成批量选择、背包空间计算和配置读写可靠性问题

## 安装

1. 安装与 Minecraft 版本和模组加载器匹配的 JsMacros。
2. 从 Releases 下载 `粘液助手 V4.5.4.zip`。
3. 解压后将整个“粘液助手”文件夹放入 JsMacros 脚本目录。
4. 进入服务器并在副手持有粘液科技指南。
5. 在 JsMacros 中运行 `粘液助手 V4.5.4.js`。

完整操作方式、配置说明和常见问题请查看 [使用说明](使用说明.md)。

## 使用前须知

- 不同服务器的 Slimefun 附属、菜单槽位和工作站结构可能不同，请先用普通材料小批量测试。
- 自动合成前请预留足够的背包空间，并确认仓储和工作站处于交互范围内。
- 使用自动操作前，请确认服务器规则允许客户端脚本。
- 日志保存在 `logs/slimefun-helper.log`，遇到问题时请同时提供日志和游戏截图。
